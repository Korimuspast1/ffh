# Этапы 4–6 — Room, Network и Domain

## Этап 4: Room database

Модуль: `core/core-database`.

Добавлено:

- `LexoraDatabase`
- `LexoraTypeConverters`
- Entity-модели:
  - `UserEntity`
  - `LanguageEntity`
  - `CourseEntity`
  - `UnitEntity`
  - `LessonEntity`
  - `ExerciseEntity`
  - `WordEntity`
  - `GrammarRuleEntity`
  - `StoryEntity`
  - `UserProgressEntity`
  - `AchievementEntity`
  - `UserAchievementEntity`
  - `QuestEntity`
  - `UserQuestEntity`
  - `ShopItemEntity`
  - `UserInventoryEntity`
  - `LeaderboardEntity`
  - `StreakEntity`
  - `SrsCardEntity`
- DAO:
  - `UserDao`
  - `CourseDao`
  - `ProgressDao`
  - `GamificationDao`
- Все observe-запросы возвращают `Flow`.
- Подготовлены converters для `Instant` и enum-типов.
- Подготовлен механизм миграций через `Room Migration`.

## Этап 5: Network layer

Модуль: `core/core-network`.

Добавлено:

- Kotlinx Serialization DTO.
- Retrofit API interfaces для эндпоинтов `/api/v1/...`:
  - `AuthApi`
  - `UserApi`
  - `CourseApi`
  - `LessonApi`
  - `LeaderboardApi`
  - `QuestApi`
  - `ShopApi`
  - `DictionaryApi`
  - `SrsApi`
  - `AchievementApi`
  - `FriendsApi`
- `LexoraNetworkDefaults`:
  - общий `Json`
  - OkHttpClient factory
  - Retrofit factory
- `AuthHeaderInterceptor` для JWT Bearer token.
- WebSocket contracts:
  - `LeaderboardSocketEvent`
  - `DuelSocketEvent`
  - `LexoraSocketClient`

## Этап 6: Domain layer

Модуль: `domain`.

Добавлено:

- Чистые domain-модели без Android-зависимостей.
- Repository contracts:
  - `AuthRepository`
  - `CourseRepository`
  - `ProgressRepository`
  - `PracticeRepository`
  - `DictionaryRepository`
  - `GamificationRepository`
- Use cases:
  - `ValidateEmailUseCase`
  - `ValidatePasswordUseCase`
  - `CalculateSrsReviewUseCase` — SM-2 spaced repetition logic
  - `CalculateLessonSummaryUseCase`
